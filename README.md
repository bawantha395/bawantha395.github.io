## Upload to GitHub

1. Extract the ZIP.
2. Upload the extracted contents to the root of `bawantha395/bawantha395.github.io`.
3. Keep `index.html`, `styles.css`, `script.js`, `slideshows.js` and the `assets` folder together.
4. Commit the upload and wait for GitHub Pages to finish deploying.

This is a static website. No build command or installation is required.
