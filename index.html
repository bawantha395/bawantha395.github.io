Featured cloud project01

AWS EKS microservices platform

I built a reusable cloud platform that brings infrastructure, releases and monitoring together. Terraform creates the foundation, GitHub Actions builds the images, and Argo CD keeps the cluster in sync with Git.

TerraformAWS EKSGitHub ActionsArgo CDPrometheusGrafana
Inside the project +

Infrastructure

Separate Terraform modules cover the foundation, EKS, database, registry and DNS services. Parameters support different environments.

Delivery

Parallel image builds publish to ECR. Kustomize bases and overlays keep configuration organized across staging namespaces.

Networking & visibility

Route 53 and CloudFront route requests through an ALB ingress with SSL. Prometheus and Grafana expose memory and quota metrics through custom ServiceMonitor resources.

What I checked

The build pipeline completed in under four minutes. In a simulated load test, the gateway scaled from one to five replicas when CPU utilization reached 326 percent.
