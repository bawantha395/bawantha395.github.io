AWS EKS GitOps
Microservices Platform

I wanted to understand the full release path. So I built a platform where Terraform defines the infrastructure and Git holds the desired application state.

AWS EKSTerraformArgo CDKustomizeGitHub Actions
Explore the sourceExplore the architecture
What I built and checked +

My contribution

I provisioned AWS with reusable Terraform modules, created environment configurations with Kustomize and implemented GitOps delivery through Argo CD. GitHub Actions tests the code, checks Terraform plans and builds images in parallel.

What I checked

The pipeline completed in under four minutes. A simulated load test increased gateway replicas from one to five during a 326% CPU utilization spike. Prometheus and Grafana exposed memory and quota metrics.
